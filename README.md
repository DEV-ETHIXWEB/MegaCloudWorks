# MegaCloudWorks — Redesign

Production rebuild of the MegaCloudWorks marketing site: a blended Swiss /
Brutalist / Neumorphic / Glassmorphic / Claymorphic design system built into
one coherent visual language, on React + Vite + Tailwind v4 + Motion + React
Router.

## Pages

- `/` — Home
- `/about` — About
- `/services` — Services
- `/work` — Work index
- `/work/:slug` — Case studies (Fieldly, Stamp, Slate, Prophy, Leadr) with live, interactive phone UI
- `/contact` — Contact
- `/concepts` — Original 6-style design comparison, kept for reference

## Development

```bash
npm install
npm run dev      # start dev server
npm run build    # production build
```
